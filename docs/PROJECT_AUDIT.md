# Project audit

The pre-migration project has a React/Vite customer storefront in `src`, a lazy React admin under `src/admin`, and an Express/SQLite API under `server`. Session, CSRF, origin and role checks protect API writes. Root scripts run Vite and Node; production serves a single SPA build. Maintained source is JavaScript/JSX. Existing tests cover commerce, financial calculations, auth and responsive navigation.

Problems: storefront and administration share one entry; API imports constants and financial logic from the UI tree; the browser demo imports backend validation. File locations and deployment documentation still describe the previous layout. Finance UI has a hand-built detail overlay rather than the accessible shared modal. Financial ledgers are empty because no provider exists. Demo mode is the current local default and must be explicitly disabled at production build time. The storefront checkout remains simulated. Existing large media and storefront bundle need further optimization; assets referenced through public URLs cannot be safely removed by import analysis alone.

Plan: move storefront to `frontend`, admin to `backend/admin`, API to `backend/api/src`, and reusable validation/calculations/constants to `backend/shared`. Keep one root package/lockfile to avoid duplicate installations, with separate frontend/admin Vite configurations and build outputs. Update imports, test paths, Node scripts and static serving. Preserve local database locations and schemas. Remove obsolete locations only by moving their contents. Retain uncertain assets and inspection scripts as development evidence. Fix shared modal usage and route/deployment checks. No production provider transactions or live financial records will be changed.

No sensitive tracked environment, key or SQLite files were found. There are no unrelated Phoenix app modules to remove. No additional package or asset has been established as unused in this audit. Real gateway webhooks, transfers/refunds, reconciliation and external email/carrier services remain unconfigured.
